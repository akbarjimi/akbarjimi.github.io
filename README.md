# akbarjimi.github.io

وب‌سایت شخصی محمد اکبری — ساخته‌شده با HTML، CSS و JavaScript خالص.

## ساختار

- `index.html` — خانه
- `projects.html` — پروژه‌ها
- `purser.html` — مستندات Purser
- `courses.html` — دوره‌ها
- `blog.html` — بلاگ
- `notes.html` — یادداشت‌ها
- `movies.html` / `series.html` / `books.html` / `papers.html` / `games.html` — تجربه‌های رسانه‌ای
- `404.html` — صفحهٔ خطا
- `css/style.css` — استایل‌ها
- `js/data.js` — منبع داده
- `js/main.js` — اسکریپت
- `assets/notes/` — تصاویر یادداشت‌ها

## انتشار روی GitHub Pages

1. مخزن را روی GitHub بسازید (نامش `akbarjimi.github.io`).
2. همهٔ فایل‌ها را پوش کنید.
3. تنظیمات مخزن → Pages → Source: `main` / root.
4. آدرس نهایی: `https://akbarjimi.github.io/`

## میانبرها

- **`Ctrl+K` یا `/`** — جستجوی سراسری
- **`ESC`** — بستن جستجو
- **`↑` / `↓` / `Enter`** — ناوبری در نتایج جستجو
